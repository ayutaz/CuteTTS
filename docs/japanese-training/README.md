## 読み方

情報を次の4つに分けて書きます。**「作った」と「良くなった」を
混同しないための決まりです。**

| 状態 | 意味 |
|---|---|
| 確認済み | 手元の実装、公開モデル、公式の文書、論文のいずれかで確かめられる |
| 決定済み | このプロジェクトとして決めた方針 |
| 提案 | 現時点の案。実験の結果しだいで変わる |
| 未確定 | 測るか、判断するかが必要 |

**達成条件は結果を見る前に決め、あとから動かしません。**
一度これをやって、比較の基準そのものが 5.2 ポイントずれました。
**差を述べるときは、そのばらつきも必ず併記します**
（たまたま良かっただけの差を「改善した」と言わないため）。

|---|---:|---|---|

| **人間の録音** | **5.59%** | — | 同じ手順で測った本物の音声。**測定側の誤差** |

| 抑揚の指標（240文） | 学習前 | いま | 人間どうし | **測定の限界** |
|---|---:|---:|---:|---:|
| 声の高さの動きの似かた | +0.024 | +0.091 | +0.382 | **+0.367** |
| アクセントの山の位置が人間と一致する割合 | 35.2% | 43.6% | 64.5% | **75.0%** |

**声の高さの動きは、「人間どうし」の値が測定の限界とほぼ同じでした**（R-050）。
つまりこの指標では、**人間の上手さと測定の限界を区別できません**。
アクセントのほうは限界が人間を上回るので、**伸びしろを見分けられます**。

## 結論

### 読み上げの精度は、これ以上は伸びない

モデル自身の誤りは 25.4 → **約 2.0 ポイント（92% 削減）**まで減りました。
**テキストの前処理・計算量・データ量のどれも、もう効きません。**

- 計算量を4倍にしても 0.33 ポイント（ばらつきの範囲内。R-055）
- データを18倍にしても 0.59 ポイント（同じくばらつきの範囲内。R-061）
- **ばらつきの中で最も都合のよい値を採っても、1,000 時間のデータで
  人間の録音の水準には届きません**

残った約 2.0 ポイントが何なのかは分かっていません。手がかりとして、
**テキスト変換そのものが読みを間違えている**例が見つかっています
（[execution-log.md](execution-log.md) の J5。**まだ測っていません**）。

### 抑揚は人間に届いていない

**13 通り試して、効いたのは1つだけ**でした —
**これから読む数モーラ先までの声の高さを、音声を作る部分に直接渡す**と、
声の高さの動きが人間に近づきます（+0.104。ばらつきを考えても確かな差）。

ただし**その「声の高さ」をどこから持ってくるかが問題**です。
テキストから予測しても実際の高さとは +0.113 しか一致せず、
**アクセント辞書に至っては、声の高さの動きの情報をまったく持っていません**（-0.001）。
**アクセントの山の位置は、正しい高さを与えても動きませんでした。**

そのため、**同じ台詞を読んだ人間の録音がある場合にだけ**使えます。

## 学習の構成

最初の段階で、下の「学習する」と書いた部分をすべて同時に更新する方式を通しました。
GPU メモリは 4.15 GB しか使わないので、16 GB のカードに収まります。

| 部分 | 扱い | 根拠 |
|---|---|---|
| 音声を圧縮・復元する部分 | **学習しない** | 日本語でもそのまま使えると確認済み（D-003） |
| 声の特徴を取り出す部分 | **学習しない** | 未確定のまま（D-004） |
| テキストの埋め込み / 音声を読み取る部分 / 言語モデル本体 | 学習する | 確定 |
| 音声を作る部分 | 学習する | **学習させないと 0.78 ポイント悪化**（T2） |
| 話し終わりを判断する部分 | 学習する | 確定 |

**`--param-dtype float32` は必ず付けてください。**
公開モデルの重みは粗い形式で保存されており、そのまま学習しても
更新量が小さすぎて丸められ、重みが動きません（R-020）。

## 重要な境界

- 元の CuteTTS が英語・中国語で出している評価値は、**日本語の品質を保証しません**
- **データを増やすだけでは良くなりません。** 話者の多様さ、音質、
  文字起こしの正確さ、権利、重複、収録内容の偏りが効きます
- 論文に書かれた学習設定は、**ゼロから学習する場合の値**です。
  既存モデルから学習し直す場合の最適値ではありません
- 学習データはアニメ・ゲームの台詞に偏っています。
  数字を含む文は全体の 1.3% しかありません（R-010）
