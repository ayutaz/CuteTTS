## 読み方

情報を次の4状態に分けます。**「実装した」と「日本語学習が成功した」を
混同しないための規約です。**

| 状態 | 意味 |
|---|---|
| 確認済み | ローカル実装、公開checkpoint、公式README、論文のいずれかで確認できる |
| 決定済み | 明示したプロジェクト方針 |
| 提案 | 現時点の推奨案。実験結果により変更し得る |
| 未確定 | 実測または判断が必要 |

**ゴールは結果を見る前に決め、事後に動かしません**（一度やって基準線が
5.2pt 動きました）。**差はすべて信頼区間つきで述べます。**

## 結論

### 読みは閉じた

TTS由来の誤りは 25.4pt → **約2.0pt（92%削減）**。
**frontend・計算量・データ量のすべてが頭打ち**になりました。

- 計算量4倍: -0.33pt（有意差なし。R-055）
- データ量18倍: -0.59pt（有意差なし。R-061）
- **信頼区間の最も都合のよい端で計算しても、1,000時間で床に届きません**

残る約2.0pt の正体は未解明です。手がかりは
[frontend 自身の読み誤り](execution-log.md)（J5。**未測定**）。

### 抑揚は届いていない

**13通りの手段のうち、動いたのは1つだけ**でした —
**F0 を先読みで DiT head の adaLN に渡す**と輪郭が動きます（+0.104、有意）。

ただし**供給側がありません**。テキストからの予測は実測と +0.113 しか相関せず、
**辞書は輪郭の形を一切持っていません**（-0.001）。
**アクセント核は、正しい F0 を与えても動きません。**

同じ台詞を読んだ人間の音声があるとき（**韻律転写**）だけ使えます。

## 学習の構成

S0 で以下をすべて同時に train する full fine-tuning を通しました。
VRAM は 4.15 GB（microbatch 1）で、16 GB に収まります。

| Component | 方針 | 状態 |
|---|---|---|
| Audio VAE | **freeze** | 確定（P1c: CER差 +0.58pt。D-003） |
| Speaker Encoder | **freeze** | 提案（D-004） |
| Text embedding / Patch Encoder / Causal LM backbone | train | 確定 |
| Flow/Diffusion Head | train | **凍結すると +0.78pt 悪化**（T2） |
| Stop Predictor | train | 確定 |

**`--param-dtype float32` は必須です**（R-020）。

## 重要な境界

- 公式モデルの英語・中国語での公開評価値は、**日本語品質を保証しません**
- **データ量だけでは成功しません。** 話者多様性、音質、文字起こし精度、権利、
  重複、収録分布が効きます
- 論文の pretraining 設定は再現の参考値であり、**継続学習の最適設定ではありません**
- 学習データは anime / visual novel domain に偏っています。
  gol corpus で数字を含む文は 1.3% しかありません（R-010）
